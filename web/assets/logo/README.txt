CARPETA DEL LOGO DEL PROYECTO
=============================

Para usar tu propio logo en la barra superior de Global Fire Intelligence:
1. Guarda tu imagen en esta carpeta con el nombre:
   - logo.png  (recomendado, fondo transparente)
   - o reemplaza directamente project-logo.svg

La plataforma detectará automáticamente `web/assets/logo/logo.png` (y si no existe, usará `project-logo.svg`).
